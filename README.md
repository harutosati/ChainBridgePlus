# ChainBridgePlus

ChainBridgePlus enables high-performance, distributed asset synchronization through real-time processing and auto-scaling within a robust framework manager.

With ChainBridgePlus, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/ChainBridgePlus.git`
2. `cd ChainBridgePlus`
3. Install in editable mode: `pip install -e .`

## Configuration

ChainBridgePlus is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
